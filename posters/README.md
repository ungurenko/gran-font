# Афиши со шрифтом Gran

Рецепт в два слоя: нейросеть рисует только фон без текста, буквы набирает шаблон шрифтом Gran. Модели шрифт не принимают, поэтому текст у неё никогда не просим.

В папке лежат рецепты, а не готовые картинки: сгенерированные фоны (`gen/`) в репозиторий не входят. Они тяжёлые, и любой генератор повторит их по промптам ниже. Готовые афиши — в [`../docs/`](../docs). Чтобы собрать свою, положи картинку как `gen/<стиль>.png`.

Слова на афишах по умолчанию русские («ГРАНЬ»), каждую строку можно заменить через адрес страницы.

## `styles/` — пять настроений из одного шаблона

Промпты фонов: [`styles/prompts.txt`](styles/prompts.txt).

| Стиль | Фон | Шрифт |
| --- | --- | --- |
| `faceted` | тёмно-синие кристаллические грани, холодный циановый свет | Black, белые со свечением |
| `concrete` | брутальный бетон с одной оранжевой панелью | Black, чёрные буквы, оранжевая черта |
| `concrete-behind` | тот же кадр, небо прозрачное и лежит поверх букв | Black, слово стоит за зданием |
| `riso` | рисограф: розовый и синий на кремовой бумаге | Black, синие, multiply |
| `holo` | мятая голографическая фольга | Black, чёрные |
| `blueprint` | кобальтовый чертёж с сеткой | Light, белые |

```bash
open "styles/poster.html?style=concrete&title=ГРАНЬ&top=GRAN&b1=ЛАТИНИЦА+И+КИРИЛЛИЦА"
```

Холст 1088×1360 (4:5). Шаблон — один файл: объект `S` хранит вид каждого стиля (вес, цвет заливки, режим наложения, свечение, зерно), крупное слово подгоняется по ширине само. У стиля `concrete-behind` поверх букв кладётся PNG того же кадра с прозрачным небом, поэтому крыши закрывают их низ.

## `neon/` — тёмный HUD со свечением

[`neon/poster.html`](neon/poster.html), промпт в [`neon/prompts.txt`](neon/prompts.txt). Светящиеся потоки рисует генератор, «стёкший» неон под буквами, цветную кайму и зерно — canvas.

Параметры адреса: `bg`, `title`, `top`, `topr`, `b1`, `b2`, `b3`, `seed` (форма «стёкшего» неона).

## Отрисовка без окна

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars --allow-file-access-from-files \
  --window-size=1088,1360 --virtual-time-budget=15000 \
  --screenshot=out.png "file://$PWD/poster.html?style=concrete-behind"
```

Локальные `.woff2` Chromium открывает только с флагом `--allow-file-access-from-files`. Странице нужны секунды `--virtual-time-budget`, чтобы подтянуть фон и шрифты.

## Новый стиль

1. Попроси у генератора фон без текста и прямо скажи, где оставить пустое место под заголовок («верхняя треть — спокойное тёмное поле»). Промпт сохрани рядом со стилем.
2. Добавь пресет в объект `S` файла `styles/poster.html`: вес, линия низа букв, цвет заливки, режим наложения, зерно.
3. Положи картинку как `styles/gen/<имя>.png` и отрисуй.

Крупное слово набирается Gran Black, мелкие строки — Bold и Regular. Шрифт дисплейный: мелкие надписи держатся с 20 px.
